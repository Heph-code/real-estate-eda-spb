# Анализ рынка недвижимости Санкт-Петербурга
 
Исследовательский анализ данных (EDA) объявлений о продаже квартир с сервиса Яндекс Недвижимость.
 
## О проекте
 
**Датасет:** 23 699 объявлений по Санкт-Петербургу и Ленинградской области, 2014–2019 гг., 22 признака.
 
**Цель:** выявить факторы, влияющие на рыночную стоимость жилья, и определить параметры для построения системы обнаружения аномалий и мошеннической деятельности.
 
## Структура
 
```
├── real_estate_eda_spb.ipynb   # Основной ноутбук
├── real_estate_data (2).csv    # Датасет
└── requirements.txt            # Зависимости
```

```bash
pip install -r requirements.txt
jupyter notebook real_estate_eda_spb.ipynb
```
 
## Содержание ноутбука
 
1. **Изучение данных** — размерность, типы, базовая статистика, пропуски
2. **Предобработка** — заполнение пропусков медианой, исправление типов данных
3. **Инженерия признаков** — цена за м², тип этажа, компоненты даты, соотношения площадей
4. **EDA** — распределения параметров, удаление выбросов (IQR + содержательные пороги)
5. **Анализ цены** — корреляции с числовыми и категориальными признаками
6. **Географический анализ** — цена м² в топ-10 населённых пунктах, зависимость от удалённости от центра
7. **Центральный сегмент** — профиль квартир в зоне ≤ 8 км от центра СПб
8. **Общие выводы**
## Ключевые результаты
 
| Фактор | Влияние на цену |
|--------|----------------|
| Площадь | r = +0.70 — наиболее сильный предиктор |
| Число комнат | r = +0.43 |
| Расстояние до центра | r = −0.35; центральная зона дороже на 40–50% |
| Тип этажа | первый этаж дешевле среднего на ~15%, последний — на ~10% |
| День недели / месяц | не влияют на цену |
| Год публикации | спад в 2015–2018, восстановление в 2019 (девальвация рубля) |
 
**Время продажи:** медиана 91 день, среднее 172 дня. Продажа менее чем за 45 дней сигнализирует о заниженной цене; более 250 дней — о завышенной или проблемном объекте.
 
**География:** разброс цен между лидером (СПб, ~106 тыс. ₽/м²) и аутсайдером (Выборг, ~58 тыс. ₽/м²) составляет ~82%.
